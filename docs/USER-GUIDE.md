# PVLANE 用户指南

[English](USER-GUIDE.en.md) | 简体中文

## 1. 运行环境

建议使用 Windows、macOS 或 Linux 桌面电脑，以及最新版 Chrome 或 Edge。浏览器需要支持 WebGL。项目在浏览器本地运行，不需要账户、后端或数据库。

安装 Node.js 22 LTS 后，在项目目录执行：

```sh
npm ci
npm run dev -- --port 5175
```

打开 `http://127.0.0.1:5175`。终端窗口需要在使用期间保持运行。

## 2. 新建或打开项目

首页提供两个入口：

- **新建项目**：选择“无底图”或“导入底图”。
- **打开项目**：选择此前由 PVLANE 保存的 JSON 项目文件。

项目不会自动保存。完成重要修改后，请点击右上角保存按钮，将 JSON 文件保存到本地。

## 3. 无底图创建屋面

1. 选择“新建项目”→“无底图”。
2. 点击“新增区域”，选择平屋面、单坡屋面或双坡屋面。
3. 在“区域”面板填写屋面宽和屋面长，允许范围为 2–200 m。
4. 平屋面可填写屋面高度和女儿墙高度；坡屋面可填写坡度和低檐高度，并设置坡向或屋脊方向。
5. 多个屋面应避免重叠。

## 4. 使用底图创建屋面

支持 PNG、JPG、WebP 和单页 PDF，底图文件最大 30 MB，图片边长最大 10000 像素。多页 PDF 需要先导出所需页面为单页 PDF。

1. 选择“新建项目”→“导入底图”。
2. 输入图纸中一段已知尺寸的真实长度。
3. 点击“开始标定”，依次点击这段尺寸的两个端点，再确认标定。
4. 指定北方向；图纸上方为北时可直接确认。
5. 点击“新增区域”，选择屋面类型并开始圈选。
6. 先点击屋面一条边的两个端点，再点击第三点确定矩形宽度。

滚轮用于缩放；按住中键或空格拖动画布。Backspace 退回一个点，Esc 取消当前绘制。屋面必须位于图纸范围内，且不能与已有屋面重叠。

## 5. 障碍物和禁布区

- **障碍物**具有高度，会参与占地和阴影避让。
- **禁布区**没有高度，只用于禁止组件进入指定范围。

无底图时，点击“新增障碍物”或“新增禁布区”会创建一个可编辑矩形。有底图时，在图纸上同样通过三个点绘制。每个屋面最多支持 100 个障碍物和禁布区。

修改屋面、障碍物、组件规格或布置参数后，原布置会标记为“待更新”。重新执行自动布置后才能生成最终报告。

## 6. 组件与自动布置

1. 打开“布置”页签。
2. 从项目组件库选择标准组件。组件库允许修改名称、功率、长度、宽度和拼缝。
3. 设置连排数量、组件朝向、左右通道和前后间距。
4. 点击“布置当前屋面”；存在多个屋面时也可点击“布置全部屋面”。

主要范围：倾角 0–60°，左右通道和屋面边距 0–20 m，前后间距 0–100 m，连排 1–3 排。整个项目最多布置 5000 块组件。

自动布置完成后检查状态：

- “无占地冲突”表示当前检测未发现越界、重叠或障碍物冲突。
- “待更新”表示参数已变化，画面仍显示旧布置，需要重新布置。
- 发现屋面重叠时，应先返回“区域”调整轮廓或位置。

## 7. 2D、3D 和辅助图片

2D 用于布置和冲突检查；3D 用于检查屋面、组件、阴影和最终报告视角。显示设置中可以调整背景、地面、材质和冬至真太阳时。

“叠加图片”可导入 PNG、JPG 或 WebP 作为独立参考图。每张不超过 8 MB，最多 8 张；支持移动、等比缩放、旋转、透明度、隐藏和删除。

## 8. 保存、恢复和报告

### 保存项目

点击右上角保存按钮，选择位置保存 `.json` 文件。项目文件包含底图、辅助图片、屋面、组件库和布置结果，因此含图片的项目文件可能较大。打开项目时支持的最大文件大小为 120 MB。

建议在关键阶段保存不同文件名，例如：

```text
项目名-01-屋面.json
项目名-02-布置.json
项目名-03-报告.json
```

### 生成报告

1. 确保“报告”页没有“请先更新”提示。
2. 点击“进入三维并预览报告”。
3. 调整三维视角并预览。
4. 点击“下载到…”保存 HTML；也可在报告中选择“打印 / 保存为 PDF”。

报告包含每个屋面的坡面展开面积、组件数量、装机量、组件投影占用面积和项目合计，仅用于前期方案估算。

## 9. 常见问题

### 保存按钮提示浏览器不支持

请使用桌面版 Chrome 或 Edge，并通过 `http://127.0.0.1` 访问。不要直接双击 HTML 文件。

### PDF 无法导入

确认文件是单页 PDF且不超过 30 MB。多页 PDF 请先拆分或导出所需页面。

### 修改后报告无法生成

返回“布置”，更新所有标记为“待更新”的屋面。屋面重叠、参数越界或项目超过 5000 块时也会阻止完成布置。

### 3D 空白或运行缓慢

更新显卡驱动并确认浏览器已启用硬件加速。关闭其他占用显卡的程序后刷新页面；大型项目可减少辅助图片和组件数量。

### 项目打不开

确认选择的是当前版本 PVLANE 保存的 JSON 文件，文件没有被手工破坏，且不超过 120 MB。遇到不受支持的数据时，系统会显示具体提示。

## 10. 数据与隐私

本项目没有后端上传流程。导入的图纸和项目数据在当前浏览器中处理，并在你主动保存时写入所选本地文件。发布、发送或上传这些文件前，请自行检查其中是否包含敏感项目资料。

## 11. 获取帮助

提交 GitHub Issue 时，请提供操作系统、浏览器及版本、Node.js 版本、复现步骤、实际结果和期望结果。项目文件可能含有底图和业务数据，请先确认内容可以公开，再决定是否附加。
