# PVLANE 用户指南

[English](USER-GUIDE.en.md) | 简体中文

## 1. 运行环境

建议使用 Windows、macOS 或 Linux 桌面电脑，以及最新版 Chrome 或 Edge。浏览器需要支持 WebGL。项目在浏览器本地运行，不需要账户、后端或数据库。

安装 Node.js 22 LTS 后，在项目目录执行：

```sh
npm ci
npm run dev -- --port 5175
```

打开 `http://127.0.0.1:5175`。终端窗口需要在使用期间保持运行。

## 2. 新建或打开项目

首页提供两个入口：

- **新建项目**：选择“无底图”或“导入底图”。
- **打开项目**：选择此前由 PVLANE 保存的 JSON 项目文件。

项目不会自动保存。完成重要修改后，请点击右上角保存按钮，将 JSON 文件保存到本地。

## 3. 无底图创建屋面

1. 选择“新建项目”→“无底图”。
2. 点击“新增区域”，选择平屋面、单坡屋面或双坡屋面。
3. 点击“开始圈选”，在空白画布中绘制。矩形依次点选一条边的两个端点，再点第三点确定宽度；平屋面可切换“多段线”，依次点选转角后点击起点或“闭合屋面”。边长范围为 2–200 m。
4. 平屋面可填写屋面高度和女儿墙高度；坡屋面可填写坡度和低檐高度，并设置坡向或屋脊方向。
5. 多个屋面应避免重叠。

## 4. 使用底图创建屋面

支持 PNG、JPG、WebP 和单页 PDF，底图文件最大 30 MB，图片边长最大 10000 像素。多页 PDF 需要先导出所需页面为单页 PDF。

1. 选择“新建项目”→“导入底图”。
2. 输入图纸中一段已知尺寸的真实长度。
3. 点击“开始标定”，依次点击这段尺寸的两个端点，再确认标定。
4. 指定北方向；图纸上方为北时可直接确认。
5. 点击“新增区域”，选择屋面类型并开始圈选。
6. 矩形先点击屋面一条边的两个端点，再点击第三点确定宽度。平屋面也可切换“多段线”，依次点选转角，点击起点或“闭合屋面”完成。多边形最多 64 个顶点，不能交叉或重叠；修改轮廓时可拖动顶点，完成后重新布置。

滚轮用于缩放；按住中键或空格拖动画布。Backspace 退回一个点，Esc 取消当前绘制。屋面必须位于图纸范围内，且不能与已有屋面重叠。

## 5. 障碍物和禁布区

- **障碍物**具有高度，会参与占地和阴影避让。
- **禁布区**没有高度，只用于禁止组件进入指定范围。

点击“新增障碍物”或“新增禁布区”，在空白画布或底图上通过三个点绘制矩形。双击对象或点击修改按钮可调整轮廓和高度。每个屋面最多支持 100 个附属建筑、障碍物和禁布区。

修改屋面、障碍物、组件规格或布置参数后，原布置会标记为“待更新”。重新执行自动布置后才能生成最终报告。

### 气楼、炮楼等附属建筑

1. 在“区域”中点击“新增附属建筑”，输入建筑相对屋面的高度并用三个点绘制矩形。
2. 选中建筑，启用“顶部布置组件”，填写顶部倾角和边距。
3. 返回“布置”，执行自动布置。建筑占地仍避让，顶部另外布置标准组件；建筑周围较高对象参与顶部阴影避让。
4. 顶部组件计入所属屋面的数量和装机量，不另重复增加屋面面积。关闭顶部布置或删除建筑会同时移除其顶部组件。

当前附属建筑顶部按水平平顶处理，支持旋转矩形。复杂坡顶、采光带和结构荷载需另行核对。

### 项目地点与阴影

填写可识别的城市名称后会采用离线城市参考坐标。未知地点请到“系统设置 → 项目地点 · 光照 → 填写经纬度”，应用完整经纬度；纬度范围 −90～90°，经度 −180～180°。手动坐标优先于地址文字，城市参考点不代表现场精确位置。

显示设置可选择“当前日期与时间”或“所在地冬至校核”。三维光照随坐标、日期、时间、时区和北向变化。自动布置按所在地冬至真太阳时 9–15 时的采样阴影包络校核，排间距按纬度计算；当前显示日期不改变这个设计区间。南半球采用当地冬至。冬至极夜地点不支持当前自动校核，系统会明确提示。

缺少可靠地点的旧项目保留几何与组件，但会标记待更新；补充地点后重新布置。地点、顶部规则或屋面轮廓变化后也要重新布置。

## 6. 组件与自动布置

1. 打开“布置”页签。
2. 从项目组件库选择标准组件。组件库允许修改名称、功率、长度、宽度和拼缝。
3. 设置连排数量、组件朝向、左右通道和前后间距。
4. 点击“布置当前屋面”；存在多个屋面时也可点击“布置全部屋面”。

主要范围：倾角 0–60°，左右通道和屋面边距 0–20 m，前后间距 0–100 m，双坡连排 1–6 排，平屋面和单坡连排 1–3 排。整个项目最多布置 5000 块组件。

自动布置完成后检查状态：

- “无占地冲突”表示当前检测未发现越界、重叠或障碍物冲突。
- “待更新”表示参数已变化，画面仍显示旧布置，需要重新布置。
- 发现屋面重叠时，应先返回“区域”调整轮廓或位置。

## 7. 2D、3D 和辅助图片

2D 用于布置和冲突检查；3D 用于检查屋面、组件、阴影和最终报告视角。显示设置中可以调整背景、地面、简单/标准/精细渲染质量、光照日期、当地时间、时区和阴影显示模式。

“叠加图片”可导入 PNG、JPG 或 WebP 作为独立参考图。每张不超过 8 MB，最多 8 张；支持移动、等比缩放、旋转、透明度、隐藏和删除。

## 8. 保存、恢复和报告

### 保存项目

点击右上角保存按钮，选择位置保存 `.json` 文件。项目文件包含底图、辅助图片、屋面、组件库和布置结果，因此含图片的项目文件可能较大。打开项目时支持的最大文件大小为 120 MB。

建议在关键阶段保存不同文件名，例如：

```text
项目名-01-屋面.json
项目名-02-布置.json
项目名-03-报告.json
```

### 生成报告

1. 确保所有屋面已更新布置，并消除越界、组件重叠和障碍物占地冲突；报告页会列出需要处理的屋面。
2. 点击“进入三维并预览报告”。
3. 调整三维视角并预览。
4. 点击“下载到…”保存 HTML；也可在报告中选择“打印 / 保存为 PDF”。

报告包含每个屋面的坡面展开面积、组件数量、装机量、组件投影占用面积和项目合计，仅用于前期方案估算。

## 9. 常见问题

### 保存按钮提示浏览器不支持

请使用桌面版 Chrome 或 Edge，并通过 `http://127.0.0.1` 访问。不要直接双击 HTML 文件。

### PDF 无法导入

确认文件是单页 PDF且不超过 30 MB。多页 PDF 请先拆分或导出所需页面。

### 修改后报告无法生成

返回“布置”，更新所有标记为“待更新”的屋面。屋面重叠、参数越界或项目超过 5000 块时也会阻止完成布置。

### 3D 空白或运行缓慢

更新显卡驱动并确认浏览器已启用硬件加速。关闭其他占用显卡的程序后刷新页面；大型项目可减少辅助图片和组件数量。

### 项目打不开

确认选择的是当前版本 PVLANE 保存的 JSON 文件，文件没有被手工破坏，且不超过 120 MB。遇到不受支持的数据时，系统会显示具体提示。

## 10. 数据与隐私

本项目没有后端上传流程。导入的图纸和项目数据在当前浏览器中处理，并在你主动保存时写入所选本地文件。发布、发送或上传这些文件前，请自行检查其中是否包含敏感项目资料。

## 11. 获取帮助

提交 GitHub Issue 时，请提供操作系统、浏览器及版本、Node.js 版本、复现步骤、实际结果和期望结果。项目文件可能含有底图和业务数据，请先确认内容可以公开，再决定是否附加。

### 常用组件库

在设置的组件库中新增或修改规格，点击“应用规格”后选择“新项目默认组件”，再点击“保存为常用库”。常用库保存在当前浏览器或离线程序的本地存储中，新建项目自动使用；清除存储或更换浏览器不会携带这些数据。打开已有项目仍使用文件内的组件库，点击“导入常用库”可以追加规格，不覆盖原有规格。每个库最多 50 种标准组件。

屋面类型的一级菜单显示平屋面、双坡屋面；点击“其他屋面类型”展开单坡屋面。双坡支持 1–6 排，平屋面和单坡支持 1–3 排。从双坡切换为其他类型时连排数会自动收敛到 3 排以内，需重新布置。

渲染的简洁、标准、精细三档保留。坡屋面使用彩钢纹理和厂房外观；精细模式增加中性灰电池片、混凝土墙面贴图、水泥地坪和本地 HDR 环境。材质为示意效果，HDR 不替代项目经纬度与时间计算的太阳方向。精细模式更消耗显存，所有资源支持离线。

## 编辑与键盘操作

- 系统设置即时生效；地点、北向或边距改变后需重新布置。未应用的经纬度草稿在关闭后丢弃。
- 组件规格须点击“应用规格”才生效；可点击“取消修改”恢复原值。尚有未应用修改时不能保存常用库，关闭组件库会丢弃这些草稿。
- 区域重命名：Enter 或移开焦点提交，Esc 取消并保留原名。
- 弹窗内 Tab / Shift+Tab 切换控件，Esc 关闭并返回入口。底图绘制中的 Esc 仅取消当前绘制，不关闭编辑器。
- 修改小障碍物或禁布区时可点击“定位对象”放大查看，点击“显示全图”恢复全景；“完成”应用修改，“取消”保留原几何。
- 多边形屋面当前支持平屋面；坡屋面请新建矩形区域。小窗口可收起操作面板以扩大画布。
