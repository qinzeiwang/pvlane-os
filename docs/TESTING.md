# 测试指南

简体中文 | [English](TESTING.en.md)

安装依赖后运行 `npm test`、`npm run desktop:test` 和 `npm run build`。

自动测试覆盖几何、布局、容量上限、地点阴影、组件库、项目解析、撤销历史、报告以及桌面离线校验。`src/qa-workflow.test.ts` 额外组合平屋面、单坡、双坡、屋脊方向、四种组件朝向和南北半球纬度，验证计算 → 修改 → 重新计算 → 保存读取 → 报告的一致性。

## 界面回归流程

请在桌面版 Chrome 或 Edge 中使用不含业务资料的测试图纸完成以下操作。

1. 新建无底图项目；确认空场景正常，平移按钮默认未选中。再分别尝试 PNG、单页 PDF；确认多页 PDF 被拒绝。
2. 标定真实尺寸并指定北向；圈选矩形及凹多边形屋面；测试撤回顶点、重新绘制、拖动角点、取消与应用。
3. 新增、修改、双击编辑和删除障碍物、禁布区、附属建筑。确认屋面外的对象被拒绝；启用、关闭顶部组件，检查数量同步。
4. 输入城市地点；测试非法、空白、合法手动坐标以及取消填写。用真实键盘或日期时间选择器修改光照，检查太阳位置和阴影；变更纬度后重新校核布置。
5. 修改组件规格；验证非法值不会应用、使用中不可删除、未使用可删除。保存常用库并新建项目，核对默认组件；测试后恢复原常用库。
6. 切换双坡 1–6 排、横竖排和屋脊方向；切换单坡及平屋面，确认连排上限回到 3 排。更新当前和全部屋面。
7. 测试区域及对象修改后的撤销、重做。另导入包含越界或重叠阵列的测试工程，确认占地冲突或参数待更新时报告受阻。
8. 切换简单、标准、精细；首次进入精细模式应在材质加载后自动显示。测试平移、缩放及适应窗口，确认全部屋面可见。
9. 保存 JSON、取消保存、重开文件；确认数量、容量、地点、顶部组件和待更新状态一致。打开损坏 JSON 时当前项目应保留。
10. 生成报告，核对每个屋面与合计；检查三维图片、名称转义、HTML 保存及打印为 PDF。

测试记录应注明代码版本、浏览器、覆盖流程、实际结果、问题修复及未验证项。单元测试中的保存接口模拟不能代替 Windows 原生保存位置对话框的人工验证；Web 构建也不能代替安装包验证。
