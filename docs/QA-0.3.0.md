# 0.3.0 用户流程测试记录

简体中文 | [English](QA-0.3.0.en.md)

测试日期：2026-10-01。对象：0.3.0 源码工作区和本地正式 Web 构建。界面测试使用 Chromium 内核浏览器，视口为 1280 × 720，测试资料均为模拟工程。

## 结果

- 45 个测试文件、326 项自动回归通过。其中 62 项专项回归覆盖异形屋面修改流程、旧项目画布恢复和损坏文件。
- 73 个界面检查点通过。发现的问题修复后，相关操作已在正式构建中复测。
- 4 项桌面离线校验通过；TypeScript 检查和正式构建通过。
- 最终综合场景：平屋面及气楼、双坡六排、凹多边形共 3 个屋面，718 块组件、394.90 kWp；报告入口可用。最终浏览器检查未记录运行错误。

新增批量回归组合凸、凹异形轮廓，23°、40°、−34° 纬度，四种组件朝向和两种屋面旋转角度。每组执行布置 → 修改轮廓 → 撤销重做 → 再计算 → 保存解析 → 改组件与对象 → 再计算 → 报告，检查组件边距、对象世界位置、旧结果失效及数量一致。

## 本轮修复

1. 选中列表对象不再自动滚回面板顶部，避免首次双击失效。
2. 无底图旧项目编辑时恢复空白画布，保留原米制坐标、北向和屋面。大坐标场景也不会落到画布外；导入空白画布工程后的首次编辑使用可操作的视野。
3. 未完成标定的“返回首页”正确返回创建页，保留图纸供继续标定或切换无底图。
4. 撤回顶点修改后开始新修改，会清除过期的重做记录。
5. 拖动轮廓不再误选中文字；异形编辑提示明确为拖动角点。
6. 损坏或非工程 JSON 给出中文错误提示，不覆盖当前项目。

## 验证边界

保存数据的一致性经过自动回归，项目文件导入经过实际界面操作；Windows 原生保存位置对话框的写入、取消及覆盖操作仍需人工验收。本轮未生成新的 Windows 安装包，桌面校验不能代替安装包运行测试。以上记录说明已覆盖的场景，不代表穷尽所有输入组合。

## 补充同类问题复查（2026-10-01）

本次补齐两项交互修复：

- 轮廓编辑在首次绘制前同步测量画布宽度及视野。避免打开编辑后立即拖角点时使用未初始化的像素比例，适用于屋面、障碍物和禁布区共用编辑器。
- 删除最后一个屋面后，空区域菜单仍提供“撤回删除”，可恢复屋面、对象及原布置；原布置若已过期，仍需重新计算。

已有保护也进行了代码对照：报告拒绝过期、越界、阵列重叠、障碍物冲突和屋面重叠；Escape 撤销重命名草稿；组件库阻止未应用草稿误保存；弹窗管理焦点及背景交互；小窗口布局和按钮颜色已有修复；三维材质未就绪时拒绝报告截图，地点/光照变化及精细环境加载后刷新阴影缓存。

本轮 45 个测试文件、326 项自动测试及 TypeScript/生产构建通过。新增报告回归覆盖“布置签名已更新但阵列与新增障碍物冲突”的拒绝路径。生产构建实际操作验证：打开屋面编辑后直接拖动角点，40×30 m 正常变为约 43.23×33.37 m；障碍物角点拖动后取消，重开恢复原 2×2 m；删除最后屋面后通过空区域菜单恢复，三个对象及原 83 块组件保留。未重新打包 Windows 程序；这次检查不替代上述原生保存/打印验收。
