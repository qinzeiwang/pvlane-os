# Windows 离线版

简体中文 | [English](WINDOWS-OFFLINE.en.md)

当前仓库版本为 0.3.0，提供离线版构建源码；本次尚未重新封装或发布对应的 Windows 安装包。以下安装步骤适用于实际收到的分发包，文件名中的版本号以分发包为准。

## 安装与启动

支持 Windows 10/11 的 x64 电脑。用户无需安装 Node.js、Git 或其他开发工具。

- 安装版：运行 `PVLANE-Offline-<版本号>-Windows-x64-Setup.exe`，选择安装位置。
- 免安装版：将 ZIP 完整解压到可写文件夹，运行其中的 `PVLANE Offline.exe`。不要只拷贝 EXE。
- 首次使用时输入分配给你的用户名，之后当前 Windows 用户在这台电脑上启动无需重复输入。用户名忽略大小写和首尾空格。
- 每次启动都会显示版权、用途和免责说明；点击“同意并进入工作台”后继续使用。
- 全部功能在本机离线运行；不注册账号、不上传图纸、没有在线更新服务。

## 保存与报告

顶部保存按钮打开 Windows 保存对话框，生成 JSON 项目。再次启动后，通过“打开项目”继续编辑。

布置完成后进入“报告”，生成预览。点击“下载到…”保存 HTML，或点击“保存 PDF…”直接保存 PDF。取消保存不会写入文件。

修改屋面、障碍物、禁布区或布置参数后，应重新布置再导出报告。其他操作见[用户指南](USER-GUIDE.md)。

## 用户名管理

本版本内置 20 个用户名的校验值，没有密码、设备绑定、联网核验或到期管理。用户名可在多台电脑使用，知晓用户名的人即可进入。它是简单访问门槛，不提供防破解保证。

首次验证会在当前 Windows 用户的应用数据目录保存用户名的校验值，不保存用户名明文。卸载后应用数据可能仍保留；清除 `%APPDATA%\PVLANE-Offline\activation.json` 后，下次启动会要求重新输入。更换内置用户名名单后，旧校验值不在新名单中也会要求重新输入。

用户名明文清单只提供给分发人，每位使用者应单独收到一个用户名。不要把完整清单和安装包一起分发。更换名单需要重新打包，旧安装包不会自动停用。

本地构建步骤：

```sh
npm ci
npm run desktop:users
npm run desktop:pack
```

首次生成后再次运行 `desktop:users` 会保留原名单。`.desktop-private/` 保存名单和校验文件，已加入 Git 忽略；请独立备份。`release/` 保存安装包和 ZIP，不包含用户名明文清单。
