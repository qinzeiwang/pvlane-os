# 0.3.0 更新说明

简体中文 | [English](UPDATE-0.3.0.en.md)

更新日期：2026-10-01。对比基准：GitHub 仓库上一版 `0.2.0`（提交 `195b3ee`）。

本次主要扩展地点阴影、多边形屋面、附属建筑顶部布置和组件库，并完善渲染及交互。上一版已有的标志、平移缩放、三档渲染入口和双击编辑继续保留。

## 新增与改进

### 地点与阴影

- 项目地点和经纬度接入光照与布置校核，提供 50 个离线城市参考点及手动坐标填写。
- 三维显示阴影随经纬度、日期、当地时间、时区和图纸北向变化；可切换当前光照和所在地冬至校核。
- 自动布置按所在地冬至真太阳时 9–15 时采样校核，纬度影响阴影避让和排间距。显示日期、时间与设计校核分别设置。
- 地点未确定时要求补充信息；非法经纬度、地点不匹配及极夜等情况提供提示或阻止不适用的校核。

### 屋面与附属建筑

- 平屋面支持多边形和凹多边形轮廓：多段线绘制、闭合、顶点修改、边界检查及实际面积统计。
- 气楼、炮楼等附属建筑的平顶可启用组件布置，独立设置顶部倾角和边距，并考虑相关遮挡。
- 顶部组件随工程保存、读取和撤销，数量与装机量计入屋面和项目报告；关闭顶部布置或删除建筑时移除对应组件。
- 双坡屋面同一斜面连排上限从 3 排提高到 6 排；单坡屋面放入“其他屋面类型”次级入口。

### 组件库与材质

- 增加当前浏览器保存的常用组件库及新项目默认组件，可将常用规格导入现有项目。
- 规格修改明确区分草稿和应用结果，增加“取消修改”；存在未应用规格时不能保存常用库。使用中的组件仍不可删除。
- 升级厂房墙面、屋面、地坪和光伏组件材质；精细模式采用本地混凝土贴图和 HDR 环境资源，附带第三方来源与许可说明。

## 修复与操作优化

- 修复精细模式首次加载完成后场景仍空白，以及切换渲染质量后阴影相机、环境贴图刷新导致的灰影错位。
- 报告生成除检查参数是否更新外，还检查越界、阵列重叠、屋面重叠及障碍物占地冲突；未就绪材质不会被捕获为空白报告图。
- 修复重命名按 Esc 误保存：Esc 保留原名，Enter 或移开焦点提交。
- 统一主按钮、取消按钮、渲染选中态、图片操作与勾选控件颜色，沿用既有蓝色强调色。
- 完善弹窗初始焦点、Tab / Shift+Tab 循环、背景操作隔离、Esc 关闭和关闭后焦点恢复；绘制编辑器中的 Esc 仍用于取消当前绘制。
- 修复小窗口面板遮挡工具栏，增加小障碍物和禁布区的“定位对象”，补充不可用入口的原因说明及忙碌状态禁用。

## Windows 离线构建

相对于上一版 GitHub 源码，本次加入 Electron 构建配置、安装包与免安装 ZIP 构建脚本、20 个随机用户名的本地生成工具、首次校验记忆及每次启动的许可说明。桌面端增加原生保存和 PDF 导出接口。

用户名明文和校验名单、安装包、构建目录及本地检查截图均不进入仓库；构建者自行生成并保管名单。源码浏览器版无需用户名激活。

**本次只更新源码和文档，没有重新生成或发布 0.3.0 Windows 安装包。** 使用和构建方式见 [Windows 离线版指南](WINDOWS-OFFLINE.md)。

## 旧项目与使用注意

- 建议升级前备份项目 JSON。导入后若地点缺失、校核参数改变或显示“待更新”，先确认地点与参数，再重新布置、保存和生成报告。
- 地点、北向、边距、屋面、对象或组件规格改变后需重新校核布置。显示日期改变不替代冬至设计校核。
- 多边形当前用于平屋面；坡屋面仍需矩形轮廓。保留标准组件和项目 5000 块上限。
- 本次未加入轻质组件、车棚、发电量、25 年预测或按组件/朝向分组的小计。
- 许可保持不变：个人非商业使用和商业展示允许；代码出售、收费开发及软件或代码交付等受限盈利活动需事先书面授权。以 [LICENSE.md](../LICENSE.md) 为准。
