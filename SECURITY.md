# 安全说明 / Security Policy

## 简体中文

如果发现可能导致项目文件泄露、恶意文件执行、跨站脚本或其他安全问题，请不要公开披露可直接利用的细节。请进入本仓库的 **Security → Advisories → Report a vulnerability**，通过 GitHub 私密漏洞报告提交。

报告请包含受影响版本、问题影响、最短复现条件和建议修复方向。请勿附加真实客户图纸、项目文件、凭据或个人信息。

当前仅维护仓库默认分支上的最新版本。PVLANE 在浏览器本地处理导入数据，但保存或分享项目 JSON 时，文件可能包含内嵌底图和辅助图片。

## English

If you find a vulnerability that could expose project files, execute malicious file content, enable cross-site scripting, or cause another security issue, do not publicly disclose exploitable details. Use **Security → Advisories → Report a vulnerability** in this repository to submit a private vulnerability report through GitHub.

Include the affected version, impact, minimal reproduction conditions, and a suggested fix when available. Do not attach real customer drawings, project files, credentials, or personal information.

Only the latest version on the repository's default branch is maintained. PVLANE processes imported data locally in the browser, but a saved or shared project JSON may contain embedded base drawings and image overlays.
