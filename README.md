# PVLANE

简体中文 | [English](README.en.md)

PVLANE 是一款在浏览器中运行的光伏前期方案工具，用于屋面建模、组件自动布置和装机量报告。

## 功能

- 图片/PDF 底图导入、比例标定与北向设置，无底图开始。
- 平屋面、单坡、双坡；障碍物与禁布区编辑。
- 标准组件库、自动布置、方向/间距设置，以及 2D/3D 查看。
- 项目保存与打开、撤销与重做、辅助图片叠加。
- 装机量报告：各屋面面积、光伏数量、光伏装机量、光伏占用面积及合计；预览后选择保存位置，也可打印为 PDF。

## 报告口径

屋面面积为坡面展开面积，未扣除障碍物/禁布区；光伏占用面积为组件在屋面上的投影面积合计，不含间隙和通道。装机量按实际组件额定功率累计。已计算但放不下组件的屋面可显示零；参数待更新或尚未布置的屋面需先更新。

## 本地安装与运行

目前需要将源码拉取到本地运行。请先安装：

- Git。
- Node.js 22 LTS（最低版本为 Node.js 20.19）。npm 会随 Node.js 一同安装。
- 支持 WebGL 的桌面版 Chrome 或 Edge。

然后执行：

```sh
git clone https://github.com/qinzeiwang/pvlane-os.git
cd pvlane-os
npm ci
npm run dev -- --port 5175
```

浏览器打开终端显示的地址，通常为 `http://127.0.0.1:5175`。首次执行 `npm ci` 会自动安装 React、Three.js、PDF.js 等依赖，不需要逐个安装。本项目不需要后端服务、数据库、Docker、Python或独立的 PDF 软件。不要直接双击 `index.html` 运行。

选择位置保存项目和报告需要 Chrome 或 Edge 提供的文件选择功能。

## 快速使用

1. 选择“新建项目”，使用无底图模式，或导入 PNG、JPG、WebP、单页 PDF 底图。
2. 有底图时先标定已知长度、确认北向，再用三个点圈出矩形屋面；无底图时直接填写屋面长宽。
3. 选择平屋面、单坡或双坡，按需要添加障碍物和禁布区。
4. 在“布置”中确认组件和间距，执行当前屋面或全部屋面的自动布置。
5. 在 2D 中检查边界和冲突，再进入 3D 检查效果。
6. 保存项目 JSON；所有屋面数据均为最新状态后，可预览并保存装机量报告。
